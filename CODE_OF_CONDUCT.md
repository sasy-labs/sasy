# Code of Conduct

SASY follows the standards in the [CNCF Code of Conduct](https://github.com/cncf/foundation/blob/main/code-of-conduct.md).

For SASY, reporting and enforcement are handled by the project maintainers.
Please report concerns privately to the maintainers through the repository's
**Security** tab (**Report a vulnerability**), which opens a private report that
only they can see; it is used for conduct reports as well as security ones.
